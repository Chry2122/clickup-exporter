How it works

Three steps, no account on our side, and no files uploaded to us.

1

Connect with your ClickUp token

Paste a personal ClickUp API token (it starts with pk_). It is stored only in chrome.storage.local on your device. We never see it.

2

Choose a List

Browse Workspace → Space → Folder → List and select what you want to export.

3

Download the ZIP

Attachments are saved as {ListName}/{TaskName}/{filename}, with an index.csv that lists what was exported.

Built to stay on your machine

The extension has no backend of its own. The only network calls go to ClickUp and, for Pro licenses, Lemon Squeezy.

Official ClickUp API only

Downloads use ClickUp’s official API at api.clickup.com. This product is not affiliated with, endorsed by, or sponsored by ClickUp.

Your token stays local

Your personal token is saved in the browser’s local extension storage. It is not sent to Chry's Tools, because we do not operate a server that receives it.

Organized archives

Every export is a ZIP with a predictable folder layout, plus a CSV index you can open in Excel or Google Sheets.

Free to try, lifetime Pro

The free tier is capped at 15 files and 1 List. Pro removes those limits with a one-time €19 license — no subscription.

Frequently asked questions

Straight answers. No filler.

Is this an official ClickUp product?

No. Attachment Exporter for ClickUp is made by Chry's Tools and is not affiliated with, endorsed by, or sponsored by ClickUp. It uses ClickUp’s public API with a token you provide.

Where is my API token stored?

Only in chrome.storage.local on your computer. The extension does not upload the token to a Chry's Tools server. Network requests that need the token go directly to api.clickup.com.

Do you store my attachments?

No. Files are downloaded to your computer and packed into a ZIP there. We do not host or archive your ClickUp files.

What is the difference between Free and Pro?

Free is limited to 15 files and 1 List. Pro is a one-time €19 lifetime license that removes those limits. Both versions use the same export format and the same local storage model.

How do payments and license keys work?

Checkout is handled by Lemon Squeezy, which acts as the merchant of record and handles applicable taxes such as EU VAT. After purchase you receive a license key. The extension activates and periodically validates that key with api.lemonsqueezy.com.

Can I get a refund?

Yes. You can request a refund within 14 days of purchase. See the Terms and Refund Policy or email licatagiuseppechristian@gmail.com.

Which browsers are supported?

It is a Manifest V3 Chrome extension. It is intended for Google Chrome and other Chromium-based browsers that support Chrome extensions. It is not yet available on the Chrome Web Store.
